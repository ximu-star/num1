# 示例合同

## 文件

| 文件 | 说明 | 预期结果 |
|---|---|---|
| `示例合同-通用服务合同-非标.md` | 通用服务合同，付款周期 75 天、履约保证金 12%、背靠背、合同专用章等 | 高风险，15 条命中 |
| `示例合同-通用服务合同-标准.md` | 条款较完整的标准示例 | 低风险，0 条命中 |
| `示例合同-通用服务合同-非标.docx` | 非标合同的 Word 版本，用于验证 Word → PDF → MinerU | 与 Markdown 版本一致 |
| `approvals.json` | mock 飞书待办数据，引用上面两份合同 | 供 8001 拉取 |

合同中的甲方/乙方名称用 `________` 占位，不包含具体公司名和业务线；可按需要替换。

## 使用方式

这两份合同已经复制到：

```text
01_可运行工具服务/contract-review-service/samples/
```

服务启动后点击前端「拉取待办」即可。也可以把 `approvals.json` 复制到该 `samples/` 目录覆盖。

## 说明

- 规则库来自工程造价/商务操作手册，部分规则名称（如“承包范围”“工期”）带有工程语境；通用服务合同可能触发“缺失”类规则，这是规则口径差异，不代表合同一定有问题。
- Word 合同需要 Word 转 PDF 能力：安装 LibreOffice，或 Windows 本地安装 Word + pywin32。
- 如果启用 Milvus，需要把手册 PDF 放到 `01_可运行工具服务/contract-review-service/samples/工程项目造价规范操作手册.pdf`，再执行 `scripts/import_manual.py --reset`。交付物未附带该手册。
