# 合同审批审查系统 · 工具调用说明

## 1. 服务与端口

| 服务 | 端口 | 职责 |
|---|---|---|
| ContractReviewService | 8001 | 飞书拉取、附件、解析、PG 规则、结果落库、评论回写 |
| ContractReview AI Service | 8002 | Agent Harness、4 个 Skill、8 个合同 Tool |
| 管理后台 | 5174 | 任务监控、失败重试、规则配置、日志查询 |

## 2. 启动

```powershell
cd 01_可运行工具服务
copy config.env.example config.env
python apply_config.py

ai-service\.venv\Scripts\python.exe ..\02_数据库初始化脚本\init_db.py
.\start-all.ps1
```

8002 必须使用：

```powershell
cd ai-service
.venv\Scripts\python.exe -m contract_review.main
```

不要用 `uvicorn contract_review.app.app:app`，否则 Windows 下 psycopg 异步连接会报事件循环错误。

## 3. 鉴权

### 8001 内部接口

请求头：

```text
X-Internal-Token: contract-internal-token
```

值来自 `CONTRACT_INTERNAL_SERVICE_TOKEN`。

### 8002 内部接口

请求头：

```text
X-Internal-Service-Token: contract-internal-token
Authorization: Bearer <用户 JWT>
```

值来自 `INTERNAL_SERVICE_TOKEN`。

管理后台接口（8001 `/api/v1/admin/*`）当前按演示环境未加鉴权，正式部署请自行加登录/角色校验。

## 4. 8001 内部接口

### 4.1 拉取待办

```bash
curl -X POST http://127.0.0.1:8001/internal/v1/approvals/pull \
  -H "X-Internal-Token: contract-internal-token"
```

返回：

```json
{"success": true, "code": "OK", "message": "拉取完成：新建 2，更新 0，预处理 2"}
```

### 4.2 查询任务列表

```bash
curl "http://127.0.0.1:8001/internal/v1/tasks?limit=20" \
  -H "X-Internal-Token: contract-internal-token"
```

### 4.3 查询任务详情

```bash
curl http://127.0.0.1:8001/internal/v1/tasks/HT-2026-007 \
  -H "X-Internal-Token: contract-internal-token"
```

返回 `task / attachments / parse / hits / result / comments / logs`。

### 4.4 触发审查

```bash
curl -X POST http://127.0.0.1:8001/internal/v1/reviews/trigger \
  -H "X-Internal-Token: contract-internal-token" \
  -H "Content-Type: application/json" \
  -d '{"approval_code": "HT-2026-007", "force": false}'
```

- 任务未 ready：返回 `QUEUED`，预处理完成后自动审查
- 已 done：返回 `ALREADY_DONE`
- blocked：返回 `TASK_BLOCKED`

### 4.5 失败任务重试

```bash
curl -X POST http://127.0.0.1:8001/internal/v1/tasks/HT-2026-007/retry \
  -H "X-Internal-Token: contract-internal-token"
```

按 `failed_stage` 从失败步骤继续。

### 4.6 回写评论

```bash
curl -X POST http://127.0.0.1:8001/internal/v1/tasks/HT-2026-007/comment \
  -H "X-Internal-Token: contract-internal-token" \
  -H "Content-Type: application/json" \
  -d '{"approval_code":"HT-2026-007","comment_text":"审查意见..."}'
```

同一 `task + attachment_version` 已成功回写时返回 `ALREADY_WRITTEN`，不会重复发评论。

## 5. 8001 管理接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/admin/summary` | 任务总数、状态分布、规则数 |
| GET | `/api/v1/admin/tasks` | 任务列表，可加 `?status=blocked` |
| GET | `/api/v1/admin/tasks/{id}` | 任务详情 |
| POST | `/api/v1/admin/tasks/{id}/retry` | 重试 blocked 任务 |
| POST | `/api/v1/admin/tasks/{id}/review?force=true` | 强制重审 |
| PATCH | `/api/v1/admin/tasks/{id}/standard-version?is_standard=true` | 标记标准版 |
| GET | `/api/v1/admin/rules` | 规则列表 |
| POST | `/api/v1/admin/rules` | 新增规则 |
| PATCH | `/api/v1/admin/rules/{id}` | 更新规则 |
| GET | `/api/v1/admin/logs?task_id=1&limit=200` | 全链路日志 |

## 6. 8002 Skill / Tool

### 6.1 Skill 清单

| SkillCode | 说明 | Tools |
|---|---|---|
| `approval-fetch` | 拉取待办、查详情、确认附件 | `list_pending_approvals`、`get_approval_detail`、`download_attachment` |
| `contract-parse` | 读取合同解析结果 | `parse_contract`、`get_approval_detail` |
| `rule-review` | PG 规则 + Milvus 语义检索 | `run_pg_rules`、`search_manual_semantic`、`get_approval_detail` |
| `report-writeback` | 保存结果、回写评论 | `save_result`、`write_comment`、`get_approval_detail` |

### 6.2 Tool 清单

| Tool | 参数 | 返回 | 说明 |
|---|---|---|---|
| `list_pending_approvals` | `limit` | 任务列表 | 触发 8001 拉取并返回任务 |
| `get_approval_detail` | `approval_code` | `ApprovalDetailData` | 附件、解析、命中、结果、日志 |
| `download_attachment` | `approval_code`, `attachment_id` | `AttachmentData` | 确认附件已下载并返回元数据 |
| `parse_contract` | `approval_code` | `ParseData` | 基本信息、条款、切片、扫描件标记 |
| `run_pg_rules` | `approval_code` | `ApprovalDetailData` | 执行确定性规则并返回命中 |
| `search_manual_semantic` | `query` | 参考片段列表 | Milvus 未启用时返回 `MILVUS_DISABLED` |
| `save_result` | `approval_code` | `ReviewResultData` | 读取已保存的审查结果 |
| `write_comment` | `approval_code`, `comment_text` | 回写结果 | 重复回写由 8001 拦截 |
| `load_skill` | `skill_code` | `SkillDefinition` | 加载 Skill 指引 |

### 6.3 8002 Agent 运行接口

```text
POST /internal/v1/agent/runs
POST /internal/v1/agent/runs/{run_id}/confirm
POST /internal/v1/agent/runs/{run_id}/cancel
```

请求体示例：

```json
{
  "conversation_id": "demo",
  "turn_id": "turn-1",
  "messages": [
    {"message_id": "m1", "type": "text", "content": {"text": "审查 HT-2026-007"}}
  ],
  "history": []
}
```

需要 `X-Internal-Service-Token` 和 `Authorization: Bearer <JWT>`。

## 7. 端到端调用示例

```bash
TOKEN="X-Internal-Token: contract-internal-token"
BASE="http://127.0.0.1:8001"

# 1. 拉取
curl -X POST "$BASE/internal/v1/approvals/pull" -H "$TOKEN"

# 2. 查任务
curl "$BASE/internal/v1/tasks" -H "$TOKEN"

# 3. 查看详情（此时应已 ready）
curl "$BASE/internal/v1/tasks/HT-2026-007" -H "$TOKEN"

# 4. 触发审查
curl -X POST "$BASE/internal/v1/reviews/trigger" \
  -H "$TOKEN" -H "Content-Type: application/json" \
  -d '{"approval_code":"HT-2026-007"}'

# 5. 查看命中与结果
curl "$BASE/internal/v1/tasks/HT-2026-007" -H "$TOKEN"
```

## 8. 数据表

| 表 | 用途 |
|---|---|
| `approval_tasks` | 审批任务、状态、附件版本、失败阶段 |
| `approval_attachments` | 附件元数据、MinIO/本地路径、哈希 |
| `contract_parses` | 解析结果、条款、切片、扫描件标记 |
| `review_rules` | 确定性规则、阈值、语义规则标记 |
| `rule_hits` | 规则命中、证据、位置、相似度 |
| `review_results` | 整体风险、摘要、关注点、评论 |
| `comment_logs` | 回写日志、评论 ID、防重复 |
| `task_logs` | Skill/Tool 调用日志、耗时、成败 |

## 9. 运行模式

| 组件 | 默认 | 说明 |
|---|---|---|
| 飞书 | mock | 读 `samples/approvals.json`，评论写 `storage/mock_comments/` |
| MinerU | mock | 读同名 `.md`；真实模式 `api`/`cli`，扫描件走 OCR |
| 存储 | local | `storage/`；可切 MinIO，自动校正服务器时钟偏差 |
| Milvus | false | 关闭时语义规则自动跳过，只跑 PG 规则 |
| LLM | 可空 | 8001 规则不需要；8002 Agent 需要真实 Key |

## 10. 示例结果（通用服务合同）

| 合同 | 结果 |
|---|---|
| `HT-2026-007` 通用服务合同（非标） | 高风险，15 条命中（高 3 / 中 9 / 低 3） |
| `HT-2026-008` 通用服务合同（标准） | 低风险，0 条命中 |

非标合同主要命中：付款周期超标、履约保证金超限、质保金比例过高、背靠背付款、合同专用章、自动续约、单方解除、保密/知识产权/数据/工期/承包范围/计量/质量标准缺失等。

评论会写入：

```text
contract-review-service/storage/mock_comments/HT-2026-007_<时间戳>.md
```
