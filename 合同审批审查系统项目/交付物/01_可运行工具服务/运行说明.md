# 运行说明

## 1. 环境要求

- Python 3.12
- Node.js 20+（仅前端需要）
- 可选：PostgreSQL 14+、MinIO、MinerU（云端或本地）、Milvus

默认配置使用 **SQLite + 本地存储 + MinerU mock + Milvus 关闭**，不依赖外部服务即可跑通。

## 2. 配置

在本目录执行：

```powershell
copy config.env.example config.env
notepad config.env
python apply_config.py
```

`config.env` 里至少需要关注：

- `LLM_API_KEY`：8002 Agent 需要；只跑 8001 规则可以不填
- `CONTRACT_MINERU_TOKEN`：使用真实 MinerU 时填写，并把 `CONTRACT_MINERU_MODE` 改成 `api`
- `CONTRACT_FEISHU_APP_ID/SECRET`：真实飞书时填写，并把 `CONTRACT_FEISHU_MODE` 改成 `real`（真实客户端仍需实现）
- `CONTRACT_STORAGE_MODE=minio`：使用 MinIO 时填写 endpoint/access/secret
- `CONTRACT_DATABASE_URL` / `AI_DATABASE_URL`：使用 PostgreSQL 时改成 `postgresql+psycopg://...`

修改后重新运行 `python apply_config.py`。

## 3. 安装 Python 依赖

```powershell
cd ai-service
python -m venv .venv
.venv\Scripts\python.exe -m pip install -U pip
.venv\Scripts\python.exe -m pip install -e .
.venv\Scripts\python.exe -m pip install -e ..\contract-review-service
```

> 两个服务共用一个 venv：`ai-service/.venv`。8001 的包也会装进这个 venv。

## 4. 初始化数据库

```powershell
cd ..
ai-service\.venv\Scripts\python.exe ..\02_数据库初始化脚本\init_db.py
```

这会建表并灌入 24 条初始规则。`init_db.py --reset` 会先删表再重建（谨慎使用）。

如果使用 PostgreSQL，请先创建数据库：

```sql
CREATE DATABASE contract_review;
```

## 5. 启动服务

```powershell
.\start-all.ps1
```

或手动启动：

```powershell
# 8001
cd contract-review-service
..\ai-service\.venv\Scripts\python.exe -m uvicorn contract_review_service.main:app --host 127.0.0.1 --port 8001

# 8002（必须用 main 启动，Selector 事件循环兼容 psycopg 异步）
cd ..\ai-service
.venv\Scripts\python.exe -m contract_review.main

# 5174 前端
cd ..\frontend
npm install
npm run dev
```

## 7. 常见配置

| 场景 | 配置 |
|---|---|
| PostgreSQL | `CONTRACT_DATABASE_URL` / `AI_DATABASE_URL` 改成 `postgresql+psycopg://...` |
| MinIO | `CONTRACT_STORAGE_MODE=minio` + endpoint/key/bucket |
| MinerU 云端 | `CONTRACT_MINERU_MODE=api` + `CONTRACT_MINERU_TOKEN` |
| MinerU 本地 | `CONTRACT_MINERU_MODE=cli` + `CONTRACT_MINERU_CLI_COMMAND` |
| Milvus | `CONTRACT_MILVUS_ENABLED=true` + URL + `CONTRACT_BGE_M3_PATH`；先导入手册 |
| Word 转 PDF | 安装 LibreOffice；Windows 本地也可用 Word + pywin32 |

## 8. 注意事项

- 8002 必须用 `python -m contract_review.main` 启动，不要用 `uvicorn` CLI，否则 Windows 下异步 PostgreSQL 会报事件循环错误。
- 默认 Feishu 是 mock：评论写到 `contract-review-service/storage/mock_comments/`。
- 默认 MinerU 是 mock：PDF/Word 会找同名 `.md` 作为解析结果。
- Milvus 默认关闭；开启前需要 `scripts/import_manual.py` 导入手册，并确认内存足够加载 BGE-M3。
- MinIO 客户端会自动读取服务器 `Date` 头校正时钟偏差；生产环境仍建议同步 NTP。
